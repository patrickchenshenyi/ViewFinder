## 0. 目标与当前状态

**目标（2026-09-25 讨论后修订）**：用 3DGS 模型推测「**现实中能拍出的好照片**」。

- 渲染只是预览/代理，其残缺**不代表视点不好**；
- 判断对象 = 「站在这里用真实相机拍，会不会是好照片」；
- 渲染缺陷只影响「**可判读性**」，永远不是否决理由；
- 允许非公式化构图（倾斜 / 留白 / 环境交代 / 氛围）。
- **输出** = 2D 效果图 + 世界系相机位姿 + 裁切建议 + VLM 点评。

## 3. 关键设计

### 3.1 坐标系与"上"方向

单目重建无绝对重力参考，"上"随首帧朝向而定。**方案**：仅用轨迹估计重力方向 `up`（不引入地平面拟合——拍摄对象可能无地面/斜面）。

- **右轴零空间法**（最终版）：pitch 是绕相机**右轴**的旋转、不改变右轴；roll≈0 时所有右轴共面于水平面，其法向即重力。实测 roll mean +0.00° / std 1.43°。
- **旧版 `mean(-R[:,1])` 已弃**：相机下轴随俯仰变化，被平均俯仰污染、偏差 **32°**（族 B 候选整体歪 ~24°，用户肉眼发现）。
- 自检：RANSAC 最大平面法向与 up 夹角 <20°（实测 11.0°）。旧版 roll 自检对"绕右轴"的轴错误**天然失明**。
- 不旋转模型，所有约束直接用 up 向量；下游 tilt 纠偏主要交给 VLM（帧无关，看渲染图竖直边/地平线）。

### 3.2 候选视角生成（`candidate_gen2.py`）

原则：**不在 6 维位姿空间均匀采样，而在"语义构图空间"采样**。四个候选族：

| 族 | 说明 |
|---|---|
| F-A 远距离平移 | 关键帧 × {back 1–5m / right-left 0.5–5m / up 0.5–2m}，平移后**重新瞄准场景中心**（模拟真实摄影师后退/横移再取景） |
| F-D 偏航（原地） | 关键帧 × {±30/45/60°} |
| F-B 近轨迹扰动 | 关键帧 × {orig/右/左/上/前 0.4m、偏航 ±15°、俯仰 ±8°} |
| F-C 主体锚定 | 密度聚类主体 × 3 相机 × {居中/左三分/右三分} |

候选数 ≈ 500–700（随 case 相机数变化）。关键点：

- **主体聚类**：高斯 xyz 体素化 + 密度阈值 + 连通域（`scipy.ndimage.label`）。
- **有效域**（M6.6.4 用除雾模型重测）：back/right/left/up **到 5m 仍 100% 可判读**；**fwd 是唯一限制方向**（>1m 进入场景内部 → 不可判读）。这推翻了 M6.0c 早期"后退无效"的旧结论（那是除雾前测的）。
- **裁切变体**：full + `crop_43`(4:3) + `crop_11`(1:1) + `crop_34`(3:4)，按「内容像素数 / 0.75」反推面积、且框内**装下全部内容**（裁后 coverage ≈0.75，保留可渲染边缘）。

### 3.3 分级过滤（美学全交 VLM）

| 级 | 做什么 | 作用 |
|---|---|---|
| **L0 可判读性**（`coverage.py`） | **黑/白双背景**渲染，`coverage` = 与任一背景差异显著的像素占比（双背景防"深色/浅色内容被误判空"），`structure` = 覆盖区梯度能量（区分白雾） | 只否决"完全不可判读"（coverage<5% 或 structure<3） |
| **screen 去重**（`screen.py`） | 分桶（族×方向×距离/意图）+ 桶内 coverage 优先 + **桶内** uv 去重 + 主体×原型配额；**移除美学加权** | 555 → ~41 个多样候选（41/41 桶全覆盖） |
| **VLM 精选**（`vlm_score.py`） | **两段式「全员入围→锦标赛」**：~41 个桶代表按 family 分层分批（每批 ~8，混合族），每批 VLM 选 top-2（**并行**）→ 幸存者 ~11 个再决出 top-3；低覆盖率候选给 VLM 看 `_crop_43.png` | 最终 top-3（**每个桶的最佳候选都被 VLM 看过**，不再被 `top20[:12]` 切掉 F-B/C/D 族） |
| **VLM 成对门控**（`refine.py`） | 微调用 `pairwise_better`（**顺序互换问两次、一致才采信、tie 回退**）+ 确定性退化守卫（主体在相机后/出画/coverage<5%） | 接受改进/拒绝退化/停滞停止 |

- **黑/白双背景**（替代早期品红+绿）：黑渲染兼作展示图（省一次渲染），白兜底深色内容误判；展示图选"内容更可见"的背景（黑覆盖率 ≥ 白覆盖率用黑，否则用白）。
- **VLM 提示词**（`vlm_prompts.py` 共享）：① 声明是 3DGS 预览、缺陷必须忽略；② 判断"站这里用真实相机拍"；③ 允许非公式化；④ 理由基于真实照片内容，禁止画质词。

### 3.4 输出

- **本期**：`top-3 { 渲染效果图, 世界系位姿, 裁切建议, VLM 点评 }`。
- **未来**：相对导航指令（`目标位姿 ∘ 当前位姿⁻¹ → 平移 + yaw/pitch`），依赖实时定位，暂不做。

## 5. 关键结论与踩坑（浓缩自历史核查）

**渲染/重建口径**：
- `render_pose.py` 复用 MonoGS `gaussian_splatting`；训练位姿渲染 vs Photo-SLAM 渲染 SSIM 0.994（**口径对齐**，非保真度——渲染 vs 真值原图 PSNR p50≈25.1dB，属重建质量）。
- 关键坑：`world_view_transform`/`projection_matrix` 须 `.transpose(0,1)`（CUDA 列主序）；MonoGS 魔改 rasterizer 需 `cam_rot_delta`/`cam_trans_delta` 两个 [3] 零向量。
- 主点用 **centered**（`focal2fov` 丢弃 cx/cy），与 cameras.json 只存 fx/fy 一致。

**除雾（`auto_dehaze.sh`，102,592 高斯）**：
- 两类残留对应两判据：① 轨道"黑屏" = **opaque 大而远**高斯（scale 0.6–1.4、z≈6–8.5）→ 几何 prune（三判据 F1 超大尺度/F2 位置离群/F3 低 op 且大）；② back"白雾" = **低 op 且屏幕大**（op<0.3、r>150px）的近相机淡雾层 → 屏幕空间定向 prune 122 个（back ten 2→75）。
- 旧 F1 `0.1×robust_r` 绝对分支误杀所有 >25cm 高斯（训练 SSIM 0.994→0.959 被拒）；F2 的 MAD z-score 在紧凑分布上失效（6×MAD≈0.3m 误判 10%），已弃。

**目标函数修订（§15 讨论核心）**：

| 旧 | 新 |
|---|---|
| argmax `beauty(渲染图)` | argmax `P(现实中能出好照片 \| 视点, 场景)` |
| 渲染缺陷 = 质量差 → 否决 | 缺陷只影响可判读性，不否决 |
| 公式化构图优先 | 非公式化同样有效，不默认奖励任何固定构图 |

- 一个 40–50% 残缺的渲染，仍产出"比所有候选都好"的视点建议——两处旧决策（L0 硬过滤、近轨迹约束）被推翻。
- **门控之争**：公式化廉价分不该当 VLM 微调的门控（会把非公式化改进判成退步）；改用 **VLM 成对比较 + 顺序互换 + 退化守卫**。
- **裁切**：好建议 = 「站在哪 + 取画面哪一块」；低覆盖率候选给 VLM 看裁切图（否则带黑边的全图误导 VLM 选近距）。

**踩坑**：
- `LD_PRELOAD=/usr/lib/.../libstdc++.so.6` + myconda python（渲染链路必需）。
- 推理模型：max_tokens 需 ≥8000 + 空返回重试 + `finish_reason=length` 重试 + 平衡括号 JSON 提取。
- `screen.py` 全局 uv 去重会**误杀远退候选**（远处视差小、主体 uv 都≈中心）→ 改**桶内**去重。
- `refine.py` 几何方向自检抓过一次 left/right 符号反。

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| 单目尺度漂移（绝对米不准） | 高度/距离用相对量、画面占比比例 |
| 部分重建（洞/浮点）带偏打分 | 打分前 mask 未重建区 + 只在轨迹凸包内采样 |
| 自由视角渲染失效 | 黑/白双背景 coverage 可判读性 + 有效域方向相关距离上限 |
| VLM 排序不可靠（第 3 vs 第 4） | 分桶去重保证多样性，VLM 只精选 + 门控，不做细粒度排名 |
| VLM 反馈震荡 | 轮数上限 + 成对门控 + 退化守卫 |
| up 估计错（恒定 roll 偏置/短轨迹） | 加权/中值抗离群；tilt 由 VLM 帧无关纠偏 |
| 语义标签缺失 | 退化为纯点密度聚类 |

## 7. 未来展望（按性价比排序）
